# 质量门禁

## A. 结构与可编辑性

- [ ] 输出为单个 SVG，`viewBox` 存在，默认尺寸为 1080×1440（3:4）；如使用自定义宽高，必须仍为 3:4 等比例，且保持可读层级；非 3:4 尺寸应在写出文件前被拒绝。
- [ ] 没有用拉伸、上下/左右留白或裁切来伪装其他比例；公众号横图、抖音 9:16 等目标已改用对应专用版式。
- [ ] 输出路径不存在，或用户明确要求覆盖并显式使用了 `--force`；旧稿和审核稿没有被静默替换。
- [ ] 标题、副标题、眉题、页脚、数字和标签是 `<text>` / `<tspan>`，不是烘焙进图片的位图。
- [ ] 显式 `\n` 被保留；自动换行不超过 3 行；标题与主体不互相遮挡。
- [ ] 边框、点阵、网格、角标、卡片和线条是独立 SVG 元素，能在矢量编辑器中选中。
- [ ] `--hero-image` 仅作为嵌入的 `<image>` data URI，原文件未被移动、改名、覆盖或压缩。
- [ ] 如使用 `--hero-remove-light`，已放大检查浅色主体边缘；该模式会把浅底图反相成黑底线稿效果，不是真实 alpha 通道，也不能用于必须完整保留白色高光的正式素材。

## B. 视觉指纹

- [ ] 能说清本稿采用的风格家族、色板、字体层级、材质和主体构图。
- [ ] 对参考图的接近仅体现在色彩气质、信息节奏、留白和材质方向；主体、文案、标识和独特图形已原创或获授权。
- [ ] “90% 相似”仅是视觉目标，不作为复制、仿冒或平台审核通过的承诺。
- [ ] 缩小到手机预览时，标题、行动信息和品牌归属仍有清晰优先级。

## C. 文本准确性

- [ ] 中文、英文、数字、日期、金额、版本号和标签逐字人工核对。
- [ ] 没有把 AI 生成的乱码、伪英文、错误数字或错别字当作装饰保留。
- [ ] 文案已给出必要上下文；不为增加“科技感”擅自编造事实、奖项、流量或官方背书。

## D. 权利与安全

- [ ] 参考图只用于学习视觉规律；使用他人原图、字体、插画、角色、摄影或品牌资产前已确认授权/许可范围。
- [ ] 不直接复制他人的 Logo、商标、二维码、产品外观识别性细节、完整独特排版或品牌专属图形系统。
- [ ] 人物照片、可识别脸、虚拟偶像或名人形象必须有肖像/使用授权；没有授权就用无脸、背影、抽象主体或自制素材。
- [ ] 不用“去水印”、擦除署名或变形来规避权利；保留来源记录，必要时注明素材来源。
- [ ] 发布到平台前另行检查平台商标、广告、版权和敏感内容规则；该 Skill 不替代法律意见。

## E. 导出与人工验收

- [ ] 先保存 SVG，再尝试 Edge/Chrome headless PNG；PNG 失败时 SVG 仍可打开且错误原因已记录。
- [ ] 人工在实际目标平台预览，检查目标比例、裁切、字体替换、透明度、对比度、压缩和安全边距；内置体系按 3:4 验收，公众号横图、抖音 9:16 等其他比例按专用版式验收。
- [ ] 通过后再用于封面或长图发布；素材或文案发生实质变化需重新检查。

## F. 多参考图覆盖

- [ ] 用户提供 `8` 张及以上参考图时，每张参考图都有独立编号、独立样片和独立提示词，不先压缩成少量风格。
- [ ] 总览中能直接看出背景明暗、主色、标题位置、主体类型、信息密度和版式骨架的差别。
- [ ] 任意两张样片如果只更换颜色、标题或装饰点阵，但主体区和信息区结构相同，视为同一方向，必须重做其中一张。
- [ ] 交付统计至少包含：参考图覆盖数、独立版式数、暗色/亮色数量、主要色相分布和未覆盖编号。
- [ ] 聚类只能发生在一一对应样片生成之后；用户没有看到完整覆盖前，不用“风格家族”替代具体参考图。
- [ ] 总览图按小组输出，避免 21 张被缩得过小而无法判断。

## G. 封面、正文与配图一致性

- [ ] 已选定具体 preset，而不是只写“科技感”“蓝色”或大组名称。
- [ ] 封面、章节页、正文页、引用页、步骤页、数据页、正文配图和结尾页共享同一套设计令牌。
- [ ] sidecar JSON 中的 preset、group、色板、字体、纹理、线条、圆角、标题位置和 motif 可复现。
- [ ] 正文配图沿用封面的主体材质与图形语言，没有临时切换到另一种摄影、插画或 3D 风格。
- [ ] 八种页面放在同一总览中时能明显看出属于同一系列，同时不同页面仍各自适合其内容用途。
- [ ] 已按 [series-consistency.md](series-consistency.md) 检查允许变化和禁止变化。

# 风格家族与风格指纹

这份参考表用于“拆解视觉规律”，不是用来逐像素复制某一张图。先记录共同语言，再替换主题、素材、文字与品牌。最终准确的中文、数字、标识、边框和网格由 SVG 完成；AI 只负责无字的主体素材。

## 共同指纹字段

- 画布：默认 1080×1440 竖版；记录安全边距、主标题区、主体区、底部行动区的相对比例。
- 色彩：记录背景色、主文字色、强调色、辅助色和对比度，不要只记一个“科技蓝”。
- 文字：记录标题字重、宽窄、倾斜、行距、字距和中英文混排关系；中文要在 SVG 中换成可编辑文本。
- 结构：记录对齐线、卡片、框线、角标、编号、点阵、网格、箭头和留白的重复规律。
- 主体：描述物体类别、视角、材质、光照、透明度与裁切方式；生成时去掉文字、商标和可识别人物。
- 质感：区分纯色、噪点、半调、扫描线、纸张颗粒、发光和阴影，避免把所有效果堆在一起。

## 1. neon-grid

黑色大留白 + 荧光黄绿色高亮，辅以细网格、低对比点阵、细线和模块标签。标题通常占上半区，主体置于中部，下方用色块或搜索胶囊收束。

- 建议色板：`#060807`、`#C9FF58`、`#F7F8EE`、`#F43651`、`#29312C`。
- 字体关系：超粗无衬线标题；小号等宽或几何英文作技术注释；中文正文用清晰黑体。
- 主体提示词方向：黑底、荧光边缘、透明结构、线框、参数标注、局部高光。
- 适合：AI 工具、开发者活动、产品发布、知识卡片。
- 避免：让 AI 直接绘制中文标题、仿制平台 Logo、把点阵铺满导致阅读层级消失。

## 2. blue-digital

饱和钴蓝/电蓝底，白色或冰蓝色粗标题，叠加半透明 3D 物体、像素块、坐标数字、虚线框和少量亮色标签。它更像“数字展会/AI 入门”视觉，不等同于黑底荧光网格。

- 建议色板：`#1535C9`、`#2458FF`、`#EEF4FF`、`#8DB6FF`、`#7DFFB2`。
- 字体关系：大号白色标题 + 小号等宽数字注释；局部标签可以用浅绿或亮黄。
- 主体提示词方向：无字的透明 3D 设备、几何装置、像素化边缘、蓝色体积光、坐标线。
- 适合：AI 入门、智能硬件、开发者活动、数字产品封面。
- 避免：把整张图做成一团蓝色渐变；让 AI 生成伪 Logo 或乱码数据；把蓝色数字风误当成 neon-grid。

## 3. industrial-mono

接近黑白工业目录或工程档案，主体用银灰或白色结构光呈现，黄色只承担少量“警示/重点”作用。网格、虚线、编号和坐标强调工艺感。

- 建议色板：`#080808`、`#EFEFEA`、`#ADB4BA`、`#818383`、`#FFEA18`。
- 字体关系：厚重压缩标题 + 小号工程编号；中文标题可使用硬朗黑体，但保留足够留白。
- 主体提示词方向：工业产品、爆炸图、机械结构、单色金属、工程制图、局部黄色标记。
- 适合：硬件、工作流、技术教程、拆解型内容。
- 避免：同时使用多个彩色霓虹渐变；主体被过度噪点遮住；把真实厂商标志放进生成图。

## 4. modern-dark

深灰/黑色现代活动信息图，顶部是清晰的活动或栏目标题，中段用一列或多列低亮度卡片承载要点，金黄、橄榄黄或浅米色只用于标题线、圆点和奖励/行动标记。重点是秩序与阅读，不是工业 3D。

- 建议色板：`#202020`、`#090A08`、`#D8A87C`、`#F2E85D`、`#F5F4ED`。
- 字体关系：现代无衬线大标题 + 米色小标题 + 黄色圆点/下划线；卡片圆角要克制。
- 主体提示词方向：无字的抽象暗色活动背景、低亮度光晕、几何圆环或简单物件；主体可很少。
- 适合：活动权益、获奖结果、清单、栏目导览、长图信息页。
- 避免：使用过重发光或大量网格；把卡片里的正文交给 AI 绘制；把真实活动承诺、金额和背书写成未核实事实。

## 5. editor-ui

白底或浅灰底，紫色/洋红色框线像设计软件面板；模块有明确标题条、选中框、圆角、连接线和“Panel / Step / Notes”式小标签。信息图比装饰更重要。

- 建议色板：`#F8F6F0`、`#17131D`、`#5D25D9`、`#BD31A8`、`#B7B3BF`。
- 字体关系：深色大标题 + 紫色标签 + 黑色正文；模块对齐优先于复杂纹理。
- 主体提示词方向：白底产品模型、轻微阴影、编辑器画布、清晰轮廓、可留白区域。
- 适合：教程、流程图、方法论、活动指南、长图分页。
- 避免：把 UI 文本交给模型生成；使用难以编辑的位图整张拼贴；元素间距不一致。

## 6. public-blueprint

颗粒蓝底、橙色块和淡黄色虚线组成“公开构建/公共蓝图”气质。可用大弧线、角标、坐标线和卡片把故事串起来，保留少量手作感。

- 建议色板：`#263989`、`#FF7050`、`#F4EE98`、`#FBFAEB`、`#142156`。
- 字体关系：粗体主标题 + 橙色英文标签；正文采用明亮色，重点词用橙色块标出。
- 主体提示词方向：蓝图、线稿、产品原型、结构示意、轻微纸张颗粒、橙色标记。
- 适合：公开招募、社区活动、产品共创、项目复盘。
- 避免：颗粒过重导致小字糊掉；把真实活动主办方标识交给模型；只复制参考图的卡片形状而没有自己的信息组织。

## 7. minimal-orb（F1 变体）

近黑色背景 + 细白字 + 一条红色发光弧面，强调安静、克制和高级留白。主体不必复杂，红色承担唯一视觉重心。

- 建议色板：`#030304`、`#F7F7F5`、`#FF244D`、`#8E8E93`、`#25252B`。
- 字体关系：轻字重大标题；细小英文说明；中文副标题短而克制。
- 主体提示词方向：黑底抽象弧面、红色渐变、柔和边缘光、低噪点、极简产品形体。
- 适合：品牌宣言、奖项、专题开场、人物/项目封面（人物需获授权）。
- 避免：加入大量贴纸、彩色图标或密集正文；红色弧面变成可识别的他人作品；过度靠近原图的独特构图。

## 风格相似度的正确用法

“90% 相似”只作为内部视觉目标：色彩气质、信息层级、留白节奏和材质方向可以接近；标题、文案、主体素材、图标、Logo、人物和独特图形应替换为原创或已授权内容。公开发布前按 [quality-gate.md](quality-gate.md) 检查版权、商标和肖像风险。

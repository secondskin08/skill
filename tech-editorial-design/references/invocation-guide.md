# `$tech-editorial-design` 调用手册

这份手册面向技术小白。你不需要记住英文参数，只要用自然语言告诉 Skill：**选哪一组、选哪一个具体方向、做什么页面、主题和文字是什么**。

## 一句话规则

先选组 → 再选具体方向 → 再选页面类型 → 填主题和文案 → 锁定同一视觉系统 → 人工检查后再继续下一页。

不要只说“做一张科技感图片”。这会让结果回到默认的黑底或蓝底。至少要说出具体方向，例如：`ref-15 三步指南/three-step-guide`。

## 2. 再选具体方向

每次调用都要写清楚三件事：

1. `ref 编号`：例如 `ref-15`。
2. `中文名/英文别名`：例如 `三步指南/three-step-guide`。
3. 你要保留的结构：例如“两个步骤卡、紫色版本标签、右侧虚线箭头”。

这样做的原因是：同一组里也有多个方向。比如组 F 的白底页面有拼贴、步骤、任务墙、规则页和引用页，不能只说“白底编辑器”。

推荐格式：

```text
$tech-editorial-design，请使用 ref-[编号] [中文名]/[英文别名]。
```

## 3. 再选页面类型

### 封面页

适合一个主题、一句主张或一个章节入口。通常有大标题、单一主视觉和少量副标题。

可以这样说：

```text
做一张 3:4 封面，主标题是“[主标题]”，副标题是“[副标题]”，页脚是“[品牌或栏目]”。
```

### 正文信息页

适合时间、规则、奖励、需求、清单和数据。需要说明信息块数量、顺序和准确内容。

可以这样说：

```text
做一张正文信息页，分成 [几] 个信息模块，模块标题依次是“[标题1]、[标题2]……”，正文我会提供准确文字，请全部用可编辑 SVG 排版。
```

### 流程/步骤页

适合教程、操作说明和阶段安排。要明确步骤数量，不要让图像模型写步骤正文。

```text
做一张流程页，共 [几] 步，步骤顺序是“[步骤1] → [步骤2] → [步骤3]”，每步保留一个独立信息卡和清晰箭头。
```

### 主体拆解页

适合设备、产品、机械结构和原理图。需要指定主体是原创、无字、无 Logo，并说清楚局部放大或尺寸线。

```text
做一张主体拆解页，中心放一个原创的 [主体]，四周安排 [数量] 个局部放大框，标注文字由 SVG 完成，不要生成伪文字。
```

### 卡片墙/案例页

适合人物、作品、客户案例、工具和用户反馈。需要说明卡片数量、是否使用授权图片或抽象占位。

```text
做一张卡片墙页，共 [数量] 张卡片；图片使用我的授权素材/无脸抽象头像，卡片底部放姓名、标签和一句说明，保持同一预设的间距和颜色。
```

## 4. 最小可用口令模板

复制下面一段，把方括号替换掉即可：

```text
$tech-editorial-design，请使用 ref-[编号] [中文名]/[英文别名]。
我要做一张 [封面/正文信息页/流程页/主体拆解页/卡片墙页/案例页]，主题是“[主题]”。
主标题：“[主标题]”；副标题：“[副标题]”；正文模块：“[模块1、模块2……]”；页脚：“[页脚]”。
请锁定这个方向的背景、配色、标题位置、主体类型、纹理和间距；不要自动换成其他风格。
图像模型只生成无字原创主体/纹理，中文、数字、表格、标签和边框由可编辑 SVG 完成。
不要复制参考图的 Logo、二维码、人物、原设备、完整文案或水印。输出 SVG 源文件和 PNG 预览，并先给我看样片。
```

```text
$tech-editorial-design，请使用 ref-02 透明设备实验室/xray-device-lab。

正文页继续使用同一黑底、银白线框、荧光绿标注系统，不要切换到蓝色数字或白底编辑器。
```

```text
$tech-editorial-design，请使用 ref-19 靛蓝公开构建/indigo-public-build。
做一套“[项目主题]”的封面和正文页：封面使用错位白底橙字标题、日期小卡和椭圆轨道；正文页继续使用靛蓝纸张、橙色标签、奶油黄虚线和定位三角。
所有项目名称、日期、地点和正文由我提供并用 SVG 排版，主体不生成 Logo 或可读文字。
```

### C｜工业档案与极简

```text
$tech-editorial-design，请使用 ref-04 工程灯泡档案/engineering-bulb-archive。
做一张“[原理主题]”正文页，使用明亮暖灰工程纸张、原创剖面主体、黑色粗标题、编号和黄色操作箭头。
后续配图也要保持明亮工程档案系统，不要自动回到黑底霓虹海报。
```

### D｜轻质彩色与符号

```text
正文页继续使用暖白、彩色几何圆和大留白，不要添加黑色点阵或复杂设备主体。
```

### E｜信息组织与规则

```text
$tech-editorial-design，请使用 ref-12 终端时间表/terminal-schedule。
做一张“[项目名称]”时间表正文页，顶部标题“[标题]”，日期依次为“[日期1]、[日期2]、[日期3]”，下方用三行黄线表格说明阶段、截止时间和负责人。
请严格保留终端风格的黑底、绿色数字和黄色表头；不要编造日期，也不要让图像模型生成表格文字。
```

### F｜白底编辑器与纸张叙事

```text
$tech-editorial-design，请使用 ref-21 暖纸引用拼贴/warm-quote-collage。
做一张“[案例主题]”正文页，顶部放引语“[引语]”，中央放我的授权截图/无脸占位，左侧做“[流程节点]”流程图，底部用橙白错位标题“[标题]”。
全页锁定暖米色纸张、靛蓝内容卡、橙色引语标签和纸张颗粒；不要换成黑底科技或普通白色商务模板。
```

## 6. 做多页内容时，如何锁定同一视觉系统

如果要做一组封面＋正文，第一次调用就把“整组锁定”说清楚：

```text
$tech-editorial-design，我要做一个 5 页竖版图文系列，请从头到尾锁定 ref-16 进阶任务墙/progression-task-wall。
第 1 页是封面，第 2 页讲基础任务，第 3 页讲进阶任务，第 4 页讲常见问题，第 5 页做行动总结。
所有页面统一使用亮白背景、黑色大标题、紫色标签、三张不同高度任务卡和右侧粉紫轨道；只改变文案和卡片内容，不改变视觉系统。
请先输出 5 页的版式计划，再逐页生成 SVG 和 PNG。
```

注意“锁定”包括：

- 画布比例和安全边距；
- 背景明暗与材质；
- 主色、强调色和文字颜色；
- 标题的位置、字重和行距；
- 主体的展示方式；
- 卡片、表格、轨道、点阵或纸纹组件；
- 页脚、搜索胶囊和行动区的位置。

允许变化的是：主题、标题、正文、日期、图片内容和少量强调词。不允许每一页偷偷换成另一组预设。

## 7. 使用自己的图片或主体时

只有在你拥有图片使用权时，才把本地图片路径写进调用口令：

```text
$tech-editorial-design，请使用 ref-06 工业设备橱窗/industrial-showcase。
我有权使用这个本地主体图片：[图片路径]。
请把它放在设备橱窗中央展示台，统一成石墨黑、钢灰、银白的产品展陈系统；保留主体轮廓，不修改图片中的品牌或人物；准确文字仍由 SVG 完成。
```

如果没有授权，使用“原创抽象主体”“无脸轮廓”“几何占位”这些说法，不要要求去水印、擦除署名或复刻他人角色。

## 8. 生成前后的人工检查

### 生成前

- 我是否写了具体 `ref-01` 至 `ref-21`，而不是只写“科技感”？
- 我是否明确了页面类型和文案？
- 需要放入的日期、金额、规则和品牌信息是否已经核实？
- 图片、人物、Logo、二维码是否有使用权限？

### 看到样片后

- 这张图的版式是否一眼能和相邻 ref 区分？
- 标题是否位置正确、能在手机上读清？
- 配图是否和文字属于同一视觉系统，而不是一张孤立的 AI 图片？
- SVG 里的文字、表格、边框和标签是否可编辑？
- 有没有手机截图外壳、伪 Logo、乱码、错误日期、二维码或水印？
- 主体是否挡住标题和正文？

如果不满意，不要只说“再科技一点”。请指出要改哪一项：

```text
P-20260819-001 退回二创：保留 ref-15 三步指南，背景和紫色边框可以保留；但标题需要上移，步骤卡改成两大一小，正文区增加 15% 留白，禁止出现黑底和蓝色渐变。
```

## 9. 可选的本地技术命令

如果主代理已经确认 21 方向覆盖，可在本地生成带编号的覆盖目录；这一步只是预览，不代表最终模板：

```powershell
$catalogRenderer = Join-Path $HOME ".codex\skills\tech-editorial-design\scripts\render_reference_catalog.py"
$coverageDir = Join-Path $PWD "coverage-v01"
python $catalogRenderer --preset ref-15 --output-dir $coverageDir
```

正式深化时使用系列渲染器，并为每个输出使用新的版本化路径，避免覆盖旧 SVG/PNG：

```powershell
$seriesRenderer = Join-Path $HOME ".codex\skills\tech-editorial-design\scripts\render_content_series.py"
$seriesDir = Join-Path $PWD "series-v01"
python $seriesRenderer --preset "ref-15" --all-pages --title "从想法到成品" --subtitle "一套封面延伸出完整正文" --footer "我的品牌" --output-dir $seriesDir --png
```

生成后可以制作八页审核总览：

```powershell
$sheetBuilder = Join-Path $HOME ".codex\skills\tech-editorial-design\scripts\build_series_contact_sheet.py"
$seriesDir = Join-Path $PWD "series-v01"
python $sheetBuilder --input-dir (Join-Path $seriesDir "ref-15") --output (Join-Path $seriesDir "ref-15-八页总览.png")
```

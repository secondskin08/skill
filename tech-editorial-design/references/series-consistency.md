# 封面到正文的一致性规则

这份规则用于把已选封面延伸成正文排版和正文配图。核心不是“颜色差不多”，而是整套内容共享同一套视觉语法。

## 一、先锁定一个具体方向

先选具体预设，例如 `ref-14 / 白底科技拼贴 / editorial-tech-collage`。不要只说“科技感”“蓝色”或只选一个大组。大组用于找方向，具体预设才是生成系列页的依据。

## 二、整套页面必须锁定的设计令牌

同一系列的所有页面必须共享：

- 背景色与背景材质；
- 正文色、主强调色、辅助强调色；
- 中文标题字体层级、正文字号关系和英文小标签风格；
- 网格、点阵、纸张颗粒、扫描线或设备框中的一种主要纹理；
- 线宽、圆角、边框和角标规则；
- 标志性图形元素，例如节点、红弧、拼图、符号矩阵、设备框或椭圆轨道；
- 主标题的位置与对齐逻辑；
- 图片处理方式，例如透明线框、半调、扁平几何、工业金属或纸张拼贴。

渲染后将这些值写入同目录的 sidecar JSON。只要 preset 不变，正文页、配图和跨平台版本不得重新随机选择这些值。不同 profile 可以有不同的构图坐标和安全区，但必须继续读取同一个 preset 的 tokens。

## 三、允许变化与禁止变化

允许变化：

- 正文页根据内容改成卡片、引用、步骤、数据或配图结构；
- 主体大小和裁切位置可变；
- 信息密度可随页面用途变化；
- 辅助图形可以重复、缩放、旋转或重新排列。

禁止变化：

- 中途换成另一套主色板；
- 封面是纸张拼贴，正文突然换成霓虹玻璃；
- 封面使用直角细线，正文改用大圆角厚卡片；
- 每页使用不同的网格、纹理或标题位置；
- 正文配图使用与封面无关的摄影、插画或 3D 材质；
- 为了“丰富”而增加不属于该 preset 的新强调色。

## 四、八种页面类型

| 页面类型 | 用途 | 一致性重点 |
|---|---|---|
| `cover` | 系列封面 | 完整展示标志性 motif 和主标题层级 |
| `section` | 章节过渡 | 减少正文，只保留标题、编号和标志性 motif |
| `body` | 普通正文信息页 | 使用同色板、同边框和同卡片语法承载 2—4 个要点 |
| `quote` | 金句或观点页 | 放大同一字体层级和标志性图形，不引入新材质 |
| `steps` | 流程步骤页 | 步骤节点沿用封面的线条、角标和强调色 |
| `data` | 数据、对比或清单页 | 表格与图表沿用同一网格、线宽和数字颜色 |
| `illustration` | 正文配图 | 少字，以同一主体材质和 motif 形成独立画面 |
| `ending` | 总结或行动页 | 回收封面元素，形成首尾呼应 |

## 五、正文配图规则

正文配图不是另开一套风格。它应当：

1. 使用同一 preset 的背景、强调色和图形语言；
2. 只保留一个主要概念或主体；
3. 减少长文本，准确中文仍由 SVG 排版；
4. 与相邻正文页形成视觉停顿，但不能像另一篇内容的封面；
5. 如果需要 AI 主体，提示词必须带入本 preset 的材质、光线、留白和负面约束。

## 六、系列验收

- [ ] sidecar JSON 中所有页面的 `preset`、`group` 和 `tokens` 一致。
- [ ] 八种页面缩略图放在一起时，一眼能看出属于同一系列。
- [ ] 去掉文字后，仍能从色板、纹理和 motif 判断使用的是哪个 preset。
- [ ] 正文页没有为了容纳信息而破坏安全边距、标题层级或对比度。
- [ ] 正文配图没有混入另一 preset 的颜色、材质和构图语法。
- [ ] 封面或正文发生实质视觉变化时，新建版本并重新人工审核。

## 七、跨平台延伸规则

当同一篇内容需要适配多个平台时，先确定一个具体 `ref`，再选择画布 profile。v05 的 profile 为：

| profile | 画布 | 主要职责 |
|---|---:|---|
| `xhs-portrait` | 1080×1440，3:4 | 小红书图文、公众号正文和正文配图 |
| `douyin-vertical` | 1080×1920，9:16 | 抖音竖屏视频帧 |
| `wechat-header` | 900×383 | 公众号头图，仅 cover |
| `social-square` | 1080×1080，1:1 | 公众号分享卡和社交卡 |
| `landscape-video` | 1920×1080，16:9 | 横版视频和宽屏内容 |

跨 profile 必须锁定：

- `background`、`paper`、`ink`、`primary`、`secondary`、`grid`、`texture`；
- 字体族、标题字重、正文层级和英文标签规则；
- 线宽、圆角、边框、角标、页脚和 motif；
- 主体的材质语言，例如透明线框、纸张拼贴、像素符号或工业金属；
- 21 个方向的 `ref` 编号、中文名、英文别名和分组归属。

跨 profile 允许变化：

- 画布宽高、构图坐标、主体大小、留白比例和信息块排列；
- 为平台界面预留的安全区；
- 同一页面角色在不同画布中的排版密度；
- 公众号头图只保留封面职责，正文信息转移到 `xhs-portrait`。

推荐公众号组合为：`wechat-header` 文章头图 → `xhs-portrait` 正文与正文配图 → `social-square` 分享卡。不要把一个 3:4 PNG 强行裁成头图，也不要把头图当正文页。

每个 profile 的 `series.json` 应记录 `profile`、`canvas`、`ratio`、`safe_area`、`reserved_zones`、`tokens`、`dedicated_layout` 和 `stretched_from_3_4`。其中 `dedicated_layout` 应为 `true`，`stretched_from_3_4` 应为 `false`。同一 ref 的 sidecar tokens 不一致，或出现新颜色、新材质、新 motif，都属于一致性失败，必须退回并重新生成。

跨平台人工验收至少包括：

- 同一 ref 的五种封面并排查看，确认“令牌一致、构图适配”；
- 目标平台的标题、主体、日期和行动信息没有进入安全区或被界面遮挡；
- 抖音 9:16 画面检查顶部 170 px、底部 210 px 保留区；
- 公众号头图、正文和分享卡分别按职责检查，不把一张图的裁切结果当成三种版式；
- 用 `build_platform_contact_sheet.py` 查看一个 profile 的 21 个方向，避免多个 ref 再次收敛成黑底或蓝底模板。

# 多参考图覆盖规则

这份规则用于用户一次提供很多参考图的情况。目标是证明“每张图都被看见”，避免只抽取少量颜色主题后生成一组彼此相似的海报。

## 一一对应阶段

1. 保留参考图原顺序，建立 `ref-01`、`ref-02`……编号。
2. 每张参考图单独记录：背景明暗、主色、标题位置、主体区域、信息密度、纹理和装饰语法。
3. 每个编号先生成一张独立样片和一份主体提示词，再考虑聚类。
4. 总览必须标出编号，用户能够从总览返回对应参考图。

## 差异度门槛

两张样片至少应在下面六项中的三项明显不同：

- 背景明暗或材质；
- 主色关系；
- 标题位置、方向或占比；
- 主体类别与展示方式；
- 信息卡、表格、拼贴、列表或留白骨架；
- 网格、轨道、像素、半调、纸张、设备框等装饰语法。

只换颜色、文字或小图标，不算新方向。

## 21 方向目录

内置目录生成器：

```powershell
python scripts/render_reference_catalog.py --all `
  --title "你的主题" `
  --subtitle "你的副标题" `
  --footer "你的品牌" `
  --output-dir "输出目录"
```

也可以只生成一个编号：

```powershell
python scripts/render_reference_catalog.py --preset ref-14 --output-dir "输出目录"
```

`ref-01` 至 `ref-21` 是覆盖样片，不代表用户最终必须保留 21 套。用户看完后可以选择 3—6 套常用方向，再用 `render_poster.py` 深化为正式模板。

## 交付统计

提交人工审核前，至少报告：

- 参考图总数与已生成样片数；
- 独立版式骨架数；
- 亮底、中性底、暗底数量；
- 黑、蓝、白、彩色、暖色等主要色相数量；
- 是否存在连续多张只有换色而结构相同；
- 未覆盖或需要用户补素材的编号。
